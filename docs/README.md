# Markdown 文档中心

欢迎使用这个纯前端 Markdown 阅读器。左侧是自动生成的文档树，右侧是当前文档，桌面端右侧还会显示本页目录。

## 快速体验

- 打开左侧的其他示例文档。
- 在搜索框输入 `Mermaid` 或 `Python`，测试文件名与正文搜索。
- 点击右上角按钮切换深色和浅色主题。
- 复制浏览器地址，即可分享当前文档。

## 支持的内容

- H1～H6 标题、段落、**粗体**、*斜体*、~~删除线~~
- 引用、列表、任务列表、链接、表格和分隔线
- 图片、GIF 和相对于当前 Markdown 的资源路径
- 行内代码、代码块与语法高亮
- Mermaid 图表与 KaTeX 数学公式
- 安全的常用 HTML 标签
